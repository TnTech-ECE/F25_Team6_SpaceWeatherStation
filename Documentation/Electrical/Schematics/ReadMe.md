# Schematic Overview

A screenshot of the KiCad schematic is provided in this directory for quick reference and readability.

The full, editable schematic file is included within the PCB project archive (`.zip`) located in the PCB folder. This file should be used for detailed inspection, modification, or replication of the design.

## Power Diagram

The included power diagram provides a high-level overview of the system power architecture external to the PCB. It illustrates how power sources (battery, solar, and external input) are managed and distributed to the board, and is intended to complement the detailed schematic rather than replace it.
