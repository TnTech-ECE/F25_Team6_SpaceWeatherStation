# Documentation

This directory contains the final design artifacts for the Personal Space Weather Station project. These materials support understanding, replication, and future development.

## Contents

- **3D Models** (`Documentation/3D Models/`)
  - STL files for system components and physical structure

- **Electrical Documentation** (`Documentation/Electrical/`)
  - Wiring schematics (PDF and source files)
  - PCB design files provided as a compressed `.zip` archive, including KiCad source files and Gerbers for manufacturing

- **Meeting Minutes** (`Documentation/Meeting Minutes/`)
  - Notes from each meeting throughout the design and development process

## Notes

These artifacts represent the final system design and development history, and provide the necessary information for building and working with the system.
